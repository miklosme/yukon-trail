## Independent playtest protocol

Use separate agents for blind exploration and constrained comparison. Blind
testers receive launch/input/capture instructions and in-game Help, without
walkthroughs, recovered rules or strategy. Constrained testers receive an exact
case, original baseline identity and inputs, but derive expected results from
the original before checking the port. Record which evidence each tester saw.
Only one agent controls a given live emulator/browser session at a time.

Each case records baseline/save identity, partner and route, visible state,
actions and timing assumptions, capture hashes, outcomes and unexplored choices.
Keep raw recordings separate from interpretation. A fresh process is not a
verified reset unless baseline restoration and boot were checked. Unknown
random seeds limit exact replay; report invariant comparisons explicitly.

At each playable milestone request human review with the runnable build,
original comparison cases, unsupported behavior and discrepancies. Human review
is pending until a playable Seattle slice exists. Do not present recovery tools
or a mockup as that review milestone.
